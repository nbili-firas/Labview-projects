# LabVIEW Virtual Instruments

## Problem 1 – Sphere Surface Area and Volume

### File

`4.2 Surface Area and Volume of a Sphere-Prob1.vi`

### Purpose

This VI calculates the surface area and volume of a sphere using the sphere diameter as the input.

### Input

- Sphere diameter (**d**)

### Calculations

Radius:

**r = d / 2**

Volume:

**V = 4/3 × π × r³**

Surface area:

**S = 4 × π × r²**

### Outputs

- Volume
- Surface Area

### LabVIEW Concepts

- Numeric controls
- Numeric indicators
- Mathematical operations
- Mathematical constants
- Graphical programming
- Data flow

# Problem 2 – Random Number Comparison

### File

`4.2 Surface Area and Volume of a Sphere-Prob2.vi`

### Purpose

This VI generates two random numbers between 0 and 1 and compares their values.

### Inputs

The VI does not require a user-entered numerical input. Random values are generated by the program.

### Process

1. Generate Random Number 1.
2. Generate Random Number 2.
3. Display both values using meters.
4. Set the maximum meter range to 1.
5. Compare Random Number 1 and Random Number 2.
6. Send the comparison result to the Boolean indicator.
7. Run the VI multiple times to observe changing results.
8. Use Highlight Execution to observe data flow.

### Output

A Boolean LED indicates the result of the comparison.

### LabVIEW Concepts

- Random number generation
- Comparison functions
- Boolean logic
- Meters
- Boolean indicators
- Data flow
- Highlight Execution

# Problem 3 – Resistor Tolerance Calculation

### File

`4.2 Surface Area and Volume of a Sphere-Prob3.vi`

### Purpose

This VI calculates the maximum and minimum resistance values for a specified resistance and tolerance.

### Inputs

- Resistance Value
- Tolerance in %

### Outputs

- MAX Resistance
- MIN Resistance

### Process

1. Enter the resistance value.
2. Enter the tolerance percentage.
3. Process the tolerance value.
4. Calculate the maximum resistance.
5. Calculate the minimum resistance.
6. Display both results on the Front Panel.
7. Test the VI using numerical values.

### LabVIEW Concepts

- Numeric controls
- Numeric indicators
- Percentage calculations
- Mathematical operations
- Graphical programming
- Engineering calculations
