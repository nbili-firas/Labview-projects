# Project 002 – LabVIEW Screenshots

## Overview

This folder contains screenshots documenting the Front Panels and Block Diagrams developed for Project 002.

The screenshots provide visual documentation of the three Virtual Instruments created during the laboratory exercises.

---

# Screenshot 1 – Problem 1

## Sphere Surface Area and Volume

### File

`Screenshot 2026-08-15 123927.png`

### Description

This screenshot shows the Front Panel and Block Diagram for the sphere surface area and volume Virtual Instrument.

The VI accepts the sphere diameter as an input and calculates:

- Volume
- Surface Area

### Development Process

The Block Diagram uses mathematical operations to:

1. Receive the sphere diameter.
2. Calculate the radius.
3. Calculate the sphere volume.
4. Calculate the sphere surface area.
5. Display the calculated values on the Front Panel.

# Screenshot 2 – Problem 2

## Random Number Comparison

### File

`Screenshot 2026-08-15 123941.png`

### Description

This screenshot shows the Front Panel and Block Diagram for the random number comparison Virtual Instrument.

The VI:

1. Generates Random Number 1.
2. Generates Random Number 2.
3. Displays both values on meters.
4. Compares the two values.
5. Sends the comparison result to a Boolean indicator.

The meters are configured with a maximum range of 1.

### File

### Description

This screenshot shows the Front Panel and Block Diagram for the resistor tolerance Virtual Instrument.

The VI:
