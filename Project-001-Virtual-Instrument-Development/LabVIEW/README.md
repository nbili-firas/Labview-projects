# LabVIEW Files

This folder contains the LabVIEW files developed for Project 001 – Virtual Instrument Development.

## Contents

The LabVIEW files contain the Virtual Instruments developed as part of this project.

The project demonstrates:

- Graphical programming
- Virtual Instrument (VI) development
- Numerical calculations
- Mathematical operations
- Boolean logic
- User interface design
- Testing and troubleshooting

## Software

National Instruments LabVIEW

## Project Applications

The Virtual Instruments were developed to perform engineering-related calculations and demonstrate how LabVIEW can be used to create interactive software tools.

For complete project information, including the objectives, methodology, and results, see the [Project 001 README](../README.md).

## Files

The `.vi` files in this folder contain the LabVIEW implementations created for the project.

> Note: LabVIEW software is required to open and run `.vi` files.
